## 💻 Run Locally

Clone the repository:

```bash
git clone https://github.com/Rohanmon80/rohan-portfolio.git
```

Go into the project:

```bash
cd rohan-portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL shown in the terminal.

## 🏗️ Build for Production

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
